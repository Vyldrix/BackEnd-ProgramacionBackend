## 📌 Guía Rápida para el Usuario

1. **Ajustar credenciales en [.env](file:///home/lautaro/Escritorio/Clases/Segundo%20A%C3%B1o/Programacion%20Backend%20/Repos/EjercicioN1-ProgramacionBackend/.env)**:
   Si ya tienes PostgreSQL instalado localmente, define la contraseña y usuario en `.env`:
   ```env
   DB_USER=tu_usuario
   DB_PASSWORD=tu_contraseña
   DB_HOST=localhost
   DB_PORT=5432
   DB_NAME=ejercicio_backend
   DATABASE_URL="postgresql://${DB_USER}:${DB_PASSWORD}@${DB_HOST}:${DB_PORT}/${DB_NAME}?schema=public"
   ```
   *(O si prefieres usar Docker, simplemente ejecuta `docker compose up -d`)*.

2. **Crear o sincronizar tablas en PostgreSQL con Prisma**:
   ```bash
   npm run prisma:push
   ```
   *(o `npm run prisma:migrate` para crear migraciones versionadas)*.

3. **Explorar datos con Prisma Studio**:
   ```bash
   npm run prisma:studio
   ```

4. **Iniciar el servidor en desarrollo**:
   ```bash
   npm run dev
   ```
