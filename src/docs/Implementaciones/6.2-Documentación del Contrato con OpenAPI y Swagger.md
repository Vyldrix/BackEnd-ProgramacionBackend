## 📄 Especificación OpenAPI 3.2.0

### Metadatos Base
- **Versión OpenAPI**: `3.2.0`
- **Título**: `API de Comercio y Checkout de Pedidos - Programación Backend`
- **Versión**: `1.0.0`
- **Servidor**: `http://localhost:3000`

### Endpoint Documentado: `POST /api/pedidos`
- **Summary**: `Procesar y crear un nuevo pedido de compra (Checkout)`
- **Descripción**: Detalla la ejecución transaccional ACID, la verificación de inventario atómica y la reversión (rollback) ante stock negativo.
- **Request Body**:
  - `application/json` con `$ref: '#/components/schemas/CrearPedidoDTO'`:
    - `usuarioId`: Entero positivo (ID del comprador).
    - `productosComprados`: Array de `ProductoCompradoDTO` (`productoId`, `cantidad`).
- **Códigos de Estado y Respuestas**:
  - **`201 Created`**: Retorna el pedido confirmado con total y desglose de detalles (`PedidoCreadoResponseDTO`).
  - **`400 Bad Request`**: Información incompleta o stock insuficiente en inventario.
  - **`422 Unprocessable Entity`**: Datos inválidos semánticamente (por ejemplo, cantidades menores o iguales a cero).
  - **`404 Not Found`**: Usuario o producto no encontrado en la base de datos.

## 🌐 Integración de Swagger UI en Express

Se integró `swagger-ui-express` en [src/app.ts](file:///home/lautaro/Escritorio/Clases/Segundo%20A%C3%B1o/Programacion%20Backend%20/Repos/EjercicioN1-ProgramacionBackend/src/app.ts):

```typescript
// Documentación interactiva Swagger UI
app.use("/api/docs", swaggerUi.serve, swaggerUi.setup(openapiDocument));
app.get("/api/docs.json", (_req, res) => {
  res.setHeader("Content-Type", "application/json");
  res.json(openapiDocument);
});
app.get("/docs", (_req, res) => {
  res.redirect("/api/docs");
});
```

### Rutas Disponibles en el Navegador:
- `http://localhost:3000/api/docs`: Interfaz gráfica interactiva de Swagger UI con botón **"Try it out"**.
- `http://localhost:3000/docs`: Redirección amigable a la documentación.
- `http://localhost:3000/api/docs.json`: Especificación OpenAPI en crudo para clientes HTTP e importación.
