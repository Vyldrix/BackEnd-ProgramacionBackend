# Walkthrough: Inyección del Cliente Prisma en la Capa de Repositorios

Se ha implementado la inyección de dependencias del cliente **Prisma ORM** en la capa de persistencia (`src/repositories/`), reemplazando la lógica en memoria por operaciones relacionales en PostgreSQL mediante métodos orientados a objetos como `create`, `findMany`, `findUnique`, `update` y `delete`.

---

## 🏛️ Estructura de la Capa de Repositorios

Cada repositorio recibe la instancia de `PrismaClient` a través de su constructor y expone métodos desacoplados mediante interfaces:

```text
src/repositories/
├── index.ts                                   # Barrel file de repositorios e interfaces
├── usuario.repository.ts                      # Operaciones CRUD con prisma.usuario
├── producto.repository.ts                     # Operaciones CRUD con prisma.producto
├── pedido.repository.ts                       # Operaciones CRUD con prisma.pedido
├── detalle-pedido.repository.ts               # Operaciones CRUD con prisma.detallePedido
└── interfaces/
    ├── usuario.repository.interface.ts
    ├── producto.repository.interface.ts
    ├── pedido.repository.interface.ts
    └── detalle-pedido.repository.interface.ts
```

- **`obtenerPorId(id)`**: `await this.prisma.usuario.findUnique({ where: { id } })`
- **`obtenerPorEmail(email)`**: `await this.prisma.usuario.findUnique({ where: { email } })`
- **`actualizar(id, datos)`**: `await this.prisma.usuario.update({ where: { id }, data: { ... } })`
- **`eliminar(id)`**: `await this.prisma.usuario.delete({ where: { id } })`
